=head1 NAME

EVP_md2
- MD2 For EVP (deprecated and removed)

=head1 SYNOPSIS

 #include <openssl/evp.h>

The following function has been removed:

 const EVP_MD *EVP_md2(void);

=head1 DESCRIPTION

MD2 is a cryptographically broken hash function standardized in RFC 1319.
B<MD2 should not be used in new applications.>

The EVP_md2() function has been removed to prevent accidental usage of this
weak hash function. MD2 is only available through the legacy provider for
explicit backward compatibility requirements.

To access MD2 when absolutely necessary for legacy compatibility:

=over 4

=item 1.

Load the legacy provider explicitly in your application

=item 2.

Use EVP_MD_fetch(NULL, "MD2", NULL) to obtain the MD2 digest

=back

B<Applications should migrate to secure hash functions such as SHA-256 or higher.>

=head1 NOTES

MD2 is cryptographically broken and should not be used (CWE-327/CWE-328).
The algorithm has known weaknesses and collisions can be found with modest
computational resources.

Use of MD2 increases security risk. Migration to SHA-256, SHA-384, SHA-512,
or SHA-3 family functions is strongly recommended.

=head1 RETURN VALUES

The EVP_md2() function has been removed. Use EVP_MD_fetch() with the
legacy provider to access MD2 if absolutely required for backward compatibility.

=head1 CONFORMING TO

IETF RFC 1319.
